# MongoDB Practice Questions

This repository contains MongoDB practice questions covering basic queries and operations.

## Topics Covered
- Comparison Operators (`$gt`, `$lt`, `$eq`, `$ne`, `$lte`)
- Logical Operators (`$and`, `$or`)
- Update Operations (`updateOne`, `updateMany`)
- Delete Operations (`deleteOne`, `deleteMany`)
- Count Documents (`countDocuments`)
- Cursor Methods (`sort`, `limit`)

## Technologies Used
- MongoDB
- MongoDB Query Language (MQL)

## Purpose
To practice MongoDB queries and improve database skills through hands-on exercises.
